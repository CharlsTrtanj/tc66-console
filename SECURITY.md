# Security policy

## Supported versions

The current `0.1.x` development series is the maintained version. Use the latest
available release or the current `main` branch when reproducing an issue.
Older development revisions are not maintained separately.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/CharlsTrtanj/tc66-console/security/advisories/new)
to report suspected security vulnerabilities. Do not publish vulnerability
details in a public issue before the maintainer has reviewed the report.

Include the affected version or commit, operating system, Python version,
transport, reproduction steps and the expected security impact. A minimal
reproduction is useful. Remove unrelated credentials, device identifiers and
personal data from attachments.

The maintainer will review reports as time permits. This project does not
provide a guaranteed response or remediation schedule.
